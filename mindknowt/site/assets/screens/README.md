# App screenshots

Drop real screenshots in here over the placeholders. Keep the filenames and
the aspect ratio and no code changes are needed.

| File | Screen | Caption on the site |
|---|---|---|
| `daily.png` | Daily | Daily shows what is due today and nothing else. |
| `knowts.png` | Knowts | Knowts groups every reminder by category and tag. |
| `log.png` | Log | Log keeps the record, with no streaks to break. |

**Aspect ratio: 402 by 874**, which is the iPhone logical screen. A straight
screenshot from any recent iPhone is already this shape, so it fits with
nothing cropped. The files here are 804 by 1748, which is that at 2x.

The frame around each one is drawn in CSS, a radius and a shadow, so these are
plain screenshots with no device chrome. Do not paste a screenshot into a
phone mockup first; it will end up framed twice.

If a replacement is a different shape, it is cropped to fill rather than
squashed, so the top and bottom of a taller image are what gets lost.
